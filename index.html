# Resumen Técnico de Funcionalidades

1. Algoritmo de Cálculo Calórico y Nutricional

Implementación de ecuaciones metabólicas (como Harris-Benedict / Mifflin-St Jeor) según el perfil del usuario (peso, altura, edad, nivel de actividad y objetivo: volumen, definición o mantenimiento). La aplicación realiza una conversión reactiva donde cada alimento añadido procesa al instante su equivalencia en energía y macronutrientes (proteínas, carbohidratos y grasas), actualizando las barras de progreso sin recargar la vista.

✓ Algoritmos de balance energético & Actualización reactiva del DOM

2. Base de Datos de Alimentos y Motor de Sugerencia de Recetas

Estructuración de un catálogo de alimentos ordenado en JSON con valores nutricionales por cada 100g. Sobre esta estructura opera un motor de recomendación que evalúa los macros restantes del usuario en tiempo real y sugiere recetas adaptadas a sus objetivos. Cada receta incluye el desglose transparente de ingredientes, gramajes exactos y aporte nutricional total.

✓ Indexación de alimentos & Filtrado dinámico de recetas por objetivos

3. Interfaz de Registro Diario y Planificación Semanal

Flujo de registro diseñado para minimizar la fricción visual: permite buscar, seleccionar gramos y asignar ingredientes a tomas específicas (desayuno, almuerzo, cena, snacks). Incluye una vista de calendario semanal para copiar, ajustar o presupuestar los días con antelación, garantizando una navegación fluida en dispositivos móviles y de escritorio.

✓ UI/UX sin fricción & Gestión de datos en cliente (Diario vs. Semanal)

4. Módulo de Control Estadístico y Seguimiento

Sistema de agregación de datos que recopila el historial de ingesta para generar métricas visuales sobre la adherencia a los objetivos nutricionales. Permite analizar tendencias semanales, promedios diarios de consumo y desviaciones de macros para dar feedback claro sobre el progreso del usuario.

✓ Agregación de datos históricos & Representación visual de rendimiento

# 🥗 Mi Nutrición

Una alternativa gratuita, ligera y sin muros de pago para el seguimiento diario de calorías y macronutrientes (proteínas, carbohidratos y grasas), diseñada para ofrecer un registro rápido y sin fricciones.

🔗 **Demo en vivo:** [mi-nutricion.replit.app](https://mi-nutricion.replit.app/)

## ✨ Características clave
- **Registro rápido:** Interfaz optimizada para añadir comidas en pocos clics.
- **Cálculo en tiempo real:** Actualización instantánea del progreso calórico y reparto de macros.
- **100% Gratuito:** Sin suscripciones ni restricciones de funciones esenciales.

## 🛠️ Tecnologías & Despliegue
- **Desarrollo & Hosting:** Replit (Rapid Prototyping & Deployment).
- **Frontend:** HTML5, CSS3, JavaScript.
- **Persistencia de Datos:** Almacenamiento local / Gestión de estado rápida.
